# My Portfolio Website

This is my personal portfolio website created as a Computer Science student at Mulungushi University.

## JavaScript Features

The website has four JavaScript features:

1. **Dark Mode** — switches the website between dark and light themes.
2. **Show/Hide Details** — allows users to show or hide extra information about my projects and skills.
3. **Responsive Mobile Menu** — hides the navigation links on smaller screens and displays a Menu button.
4. **Contact Form Validation** — checks the contact form fields before submission.

## How to Test

* Click **Dark Mode** to switch between dark and light themes.
* Scroll to **My Projects and Skills** and click **Show details** on each card.
* Open Chrome DevTools, enable the device toolbar, set the width to **375px**, and test the **Menu** button.
* Open the **Console** in Chrome DevTools and check that there are no red errors.
* Test the contact form by entering and submitting the required information.
